# Security

Please do not disclose suspected security vulnerabilities through public GitHub
issues.

Report security issues to:

**security@macaroonnetwork.com**

Canonical security policy:

https://macaroonnetwork.com/.well-known/security.txt

When reporting an issue, include the affected public component, reproducible
steps, observed impact and any relevant request/response metadata with secrets
removed.

This repository is the public MCP distribution surface. Do not include wallet
private keys, payment signatures, API credentials or unpublished infrastructure
details in reports or examples.
